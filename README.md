How to Run

1. Clone the repository:

git clone https://github.com/dasarivarun31-stack/codealpha_tasks.git

2. Open the repository in Visual Studio Code.
3. Compile a Java program. For example:

javac -d . codealpha_tasks/StudentGradeTracker.java

4. Run the program:

java codealpha_tasks.StudentGradeTracker

Repeat the compilation and execution steps for the other two programs by replacing the class name.

These commands assume the Java files declare package codealpha_tasks;.
