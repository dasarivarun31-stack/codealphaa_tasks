## Task 4: Hotel Reservation System

Run the console application from the repository root:

```text
javac codealpha_tasks\HotelReservationSystem.java
java codealpha_tasks.HotelReservationSystem
```

The application supports room searches by date and category, simulated payment
and reservations, booking lookup, cancellation, and reservation listing. Room
availability is derived from active reservations. Bookings are stored in
`bookings.csv` in the current working directory, so run the program from the
same directory to access the same reservation data.

Room rates are $89.99 per night for Standard, $149.99 for Deluxe, and $249.99
for Suite. Payment is simulated; no real payment or refund is processed.
