Student Grade Tracker

Project Description

The Student Grade Tracker is a Java-based application developed to simplify the management of student academic performance. It provides a structured approach to handling student marks and evaluating academic results.

Objectives

* Manage student academic information.
* Process subject-wise marks.
* Calculate academic performance.
* Determine student grades.
* Practice Java programming and logical implementation.

Technologies Used

* Java
* Object-Oriented Programming concepts
* VS Code
* Git and GitHub

Key Features

* Student information handling
* Marks processing
* Grade calculation
* Academic performance evaluation

How to Run

1. Install Java JDK.
2. Open the project in VS Code.
3. Open the terminal.
4. Navigate to the project folder.
5. Compile using javac StudentGradeTracker.java.
6. Run using java StudentGradeTracker.

Learning Outcomes

* Improved Java programming skills.
* Understanding of conditional statements and data handling.
* Practical experience in developing Java applications.
